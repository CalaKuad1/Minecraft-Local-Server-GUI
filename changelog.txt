# Minecraft Server GUI - Changelog

## Version 1.2.8 - 2026-09-11 RELIABILITY, SECURITY, BACKUPS & UI

### CRITICAL FIX: Backend memory leak (reached 18 GB)
- Fixed an infinite loop in the Server List Ping `pack_varint` helper. Every time
  a server was online, the status query never returned and the backend allocated
  memory forever (~25-45 MB/s). The backend could climb past 18 GB; now it stays
  around 70 MB.
- Diagnosed with py-spy (the stuck thread was in `pack_varint`) and verified with
  a flood test (1.6M log lines) plus a long-running SLP check.

### SECURITY
- The backend now requires a per-launch random token (`X-MLSG-Token`) on every
  HTTP request and `?token=` on the WebSocket, and CORS is restricted to the
  app's own origins. Before, any web page open in the browser could control the
  local server (start/stop, console commands, jar install, file access).

### WORLDS & BACKUPS
- Restore, delete, download and upload world backups.
- Automatic scheduled backups (interval + retention) via a background watchdog.
- Zip-slip and path-traversal protection on restore.
- Backups list is no longer capped at 8 items.

### CUSTOM ADDRESS (DNS)
- SRV record is created when the tunnel starts and removed when it stops, the app
  closes, a server is deleted or its subdomain changes. This prevents DNS records
  from accumulating (which filled the 200-record zone quota and caused
  "Record quota exceeded").
- The app now shows the real DNS error in the UI instead of failing silently.

### CONSOLE
- Command history (Up/Down) and Tab autocompletion with suggestions.
- Logs are cached per server: returning to the library and re-entering no longer
  clears the console.

### FIXES
- Fixed a crash: the Schedule Shutdown modal (`ShutdownTimerModal`) was
  referenced but never defined, breaking the Dashboard.
- Fixed duplicate SSH tunnel processes when starting the tunnel twice.
- Fixed the dead "Import World" button, the broken `/configure` endpoint and the
  RAM unit display.
- Fixed the missing server icon fallback (no more 404s) and Recharts size
  warnings when the Dashboard is hidden.
- `backend_debug.log` now rotates (5 MB x 3) instead of growing forever.

### UI
- Redesigned the Server Library (status filters, grid/detailed views, recently
  opened, empty state).
- Unified the look of Players, Worlds, Mods and Plugins and translated them into
  English, Spanish, French and Russian.

### BUILD & TESTS
- Removed the stale committed `backend/api_server.exe` (it was from v1.2.0 and
  could ship an outdated backend). `npm run electron:build` now rebuilds the
  Python backend first.
- Added 16 backend unit tests (varint/SLP, config manager, backups).
- Added auto-update support via electron-updater.

## Version 1.2.7 - 2026-07-09 PAPER INSTALL FIX, IMPORT FOLDER & LINUX MEMORY LEAK

### CRITICAL FIX (Issue #15 — Can't install Paper server):
- **Fixed Paper/Spigot/Fabric install failing with "Failed to download Server JAR."** — The download URL was built without lowercasing the server type, and mcutils.com returns HTTP 500 for capitalized types (e.g. "Paper"). The type is now normalized to lowercase before building the URL and the install dispatch.
- **Added retry with backoff** for transient CDN/Cloudflare errors (5xx, connection resets) on server JAR downloads, plus a browser-like User-Agent to avoid bot-blocking.
- **The real failure reason is now surfaced** to the UI (URL + HTTP status) instead of a generic message, so Paper/Spigot download issues can be diagnosed.
- **Fixed "Link to folder" button doing nothing** in the Setup Wizard — `api.importServer` was missing from the frontend API client, so the button threw a silent TypeError. The import flow now detects the engine/version from the folder and registers the server profile, with on-screen loading/error feedback.

### CRITICAL FIX (Issue #4 — Massive RAM leak on Linux):
- **Truncated oversized log lines (8KB cap) before storing them** in the in-memory deques and async log queue. Previously a force-flushed 1MB chunk (newline-less server output) could be retained per entry, allowing gigabytes to pile up across the bounded deques (1000 + 500 + 2000 entries).
- **Reused the binary read buffer** (`del`/`clear`) instead of allocating a new `bytearray` for every flushed line, reducing allocator churn and glibc arena growth that kept RSS high even after a server stopped.
- **Returned freed heap memory to the OS on Linux** via `malloc_trim(0)` after a server stops or is force-killed, so the backend's RSS actually drops instead of holding peak usage indefinitely.
- **Fixed backend log routing**: `api_client.py` and `java_manager.py` called `logging.basicConfig()` at import time (before `api_server` configured the root logger), which silently prevented the `backend_debug.log` FileHandler from ever being installed. The root logger level is now INFO (was DEBUG), removing the huge volume of compressible per-chunk debug garbage that filled disk/RAM.
- **Capped the Server List Ping JSON payload** at 1MB and bounded the Varint reader, preventing unbounded string growth from a misbehaving server.

## Version 1.2.6 - 2026-06-02 MEMORY LEAK & STARTUP SCRIPTS FIX

### CRITICAL FIX:
- **Fixed massive memory leak in `api_server`** — The binary read buffer in log reader threads could grow unboundedly when output had no newlines. Now capped at 1MB and force-flushed.
- **Fixed zombie reader threads** — Pipes are now closed before joining threads, preventing stuck daemon threads from holding references to old `ServerHandler` instances and their log history.
- **Fixed `active_handlers` leak** — Deleting a server now properly removes its handler from memory.
- **Fixed `world_size_cache` unbounded growth** — Cache now evicts oldest entries when exceeding 100 items.
- **Reduced memory fragmentation** — Changed `bytes +=` concatenation to `bytearray.extend()` in log reader.

### FIXED:
- **Startup scripts (run.sh/run.bat) no longer executed** — The app now uses direct JAR-based startup instead of running `run.sh`/`run.bat` scripts. Fixes `undefined symbol: rl_macro_display_hook` crash on Gentoo Linux / AppImage environments (Issue #11)

### FIXED:
- **Startup scripts (run.sh/run.bat) no longer executed** — The app now uses direct JAR-based startup instead of running `run.sh`/`run.bat` scripts. Fixes `undefined symbol: rl_macro_display_hook` crash on Gentoo Linux / AppImage environments (Issue #11)

## Version 1.2.5 - 2026-05-28 DNS PROXY, FIXED ADDRESSES & CONSOLE

### CRITICAL FIX:
- **Fixed backend crash on startup (.exe)** — Added missing hidden imports (`requests`, `pydantic`, `starlette`, `multipart`) to PyInstaller build
- **Error logging** — Backend crash logs are now saved to `%APPDATA%/MinecraftServerGUI/backend_crash.log`

### ERROR FEEDBACK (NEW):
- **Server error detection** — Common errors (missing mods, Java version, port conflicts, OOM) are detected and shown as structured error banners with fix suggestions
- **Mod dependency warnings** — When installing a mod that requires other mods, shows a confirmation dialog
- **Banner in Dashboard** — Clear, actionable error messages with dismiss button

### NEW: Fixed Server Addresses (DNS)
- **Permanent domain** — Each server gets a permanent address like `survival.play.tudominio.app` that never changes
- **Auto-generated** — Unique subdomain generated automatically from server name + ID (`vanilla-a3f2b`)
- **Inline editing** — Click the pencil icon to change your subdomain, with availability checking
- **Duplicate protection** — Subdomains are permanently reserved; not released when tunnel stops
- **Cloudflare DNS Proxy** — Open-source Cloudflare Worker manages SRV records (repo: MLSG-DNS-Worker)
- **Auto-Tunnel** — Tunnel starts automatically 5s after server boot (toggle in Advanced settings)

### Console Improvements
- **Search & filter** — Search bar and level badges (CMD/INF/WRN/ERR) for quick log navigation
- **Export logs** — Download button saves full console history as `.txt`
- **Polling fallback** — Console fetches logs via REST API when WebSocket is disconnected
- **Fixed WebSocket 404** — `wsproto` dependency added to fix WebSocket in .exe builds

### UI & Dashboard
- **Redesigned tunnel section** — Clean single-address display, DNS always visible, Advanced toggle
- **Local IP** — Always shown as subtitle alongside public/DNS address
- **Online/Offline badges** — Clear DNS status indicator (ONLINE/OFFLINE)
- **Premium/No Premium toggle** — Quick online-mode switch in Dashboard header
- **Boot from library** — "Boot" button on server cards to start server directly from library
- **Mods import** — Upload `.jar` files directly with file picker in Mods tab
- **Auto-restart on crash** — Toggle in Dashboard header, max 3 restart attempts

### Bug Fixes
- Fixed console tab showing "Loading..." forever (input always enabled, REST fallback works)
- Fixed logs disappearing when switching panels (Dashboard & Console stay mounted)
- Fixed Dashboard mini-console unable to send commands without WebSocket
- Various JSX/Babel parsing fixes
